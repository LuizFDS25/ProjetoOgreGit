- Feito na versão 6000.6.3f1 da Unity
- Scripts feitos no Visual Studio 2022

## Controles
| Ação | Tecla/Botão |
|---|---|
| Mover | W A S D |
| Correr (segurar) | Shift |
| Correr de costas | Automático ao correr na direção oposta da que o personagem olha |
| Agachar | Ctrl |
| Ataque | Botão esquerdo do mouse |
| Roll | Barra de espaço |
| Long Roll | Barra de espaço + Shift |
| Block (segurar) | Botão direito do mouse |
| Cast Spell | Q |
| Pummel | E |
| Quick Shot | R |
| Special 1 | 1 |
| Special 2 | 2 |
| Idle | Alterna entre Idle 1 e 2 automaticamente |
| Tomar dano (DEMO) | T |
| Resetar personagem (DEMO) | Backspace
